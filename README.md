# Timetable Maker
 
発表会向けの **タイムテーブル作成ツール**
 
開始時刻と発表時間・件数を指定するだけで、発表コマを自動生成。
ランチや休憩・特別枠を挟んだプログラムをブラウザ上で組み立て、CSVで入出力できます。
サーバー・ビルド不要の**単一HTMLファイル**で、完全にオフラインで動作します。
 
https://shok1122.github.io/timetable-maker/

## 機能
 
- 開始時刻の指定（終了時刻は発表の件数と固定枠から自動で決まります）
- **発表種別を複数定義**（名称・発表時間・質疑応答時間・件数、1コマ = 発表 + 質疑）
  - 例：`種別A` = 発表10分 + 質疑5分 × 4件、`種別B` = 発表7分 + 質疑3分 × 3件
  - 種別ごとに件数を指定すると、上から順に配置されます
  - 種別ごとに色分けして表示
- ランチ枠の開始・終了指定
- 休憩・基調講演・ポスター・授賞式など、発表以外の**特別枠**を自由に定義
- 発表順序の**手動並べ替え**（表の行をドラッグ＆ドロップ、または ▲▼ ボタン）
  - 種別をまたいで自由に入れ替え可能。時刻は種別ごとのコマ長に応じて自動で振り直されます
  - 並び順は再生成・件数変更・CSV入出力をまたいで保持されます
- 設定を変更すると即座に再生成される**インタラクティブ**なUI
- 発表タイトル・発表者を表内で直接編集
- **CSVのインポート／エクスポート**（UTF-8・Excel対応）
  - 時刻の列が無いCSV（**発表種別・タイトル・発表者だけ**の一覧）も読み込めます
  - その場合はCSVの行順のまま、開始時刻から順に自動配置。あとは開始時刻の指定と並べ替えで仕上げられます
- 操作パネルを隠して出力する**印刷 / PDF**レイアウト

## 使い方
 
1. 左側の基本設定で開始時刻を入力し、「発表種別」で発表時間・質疑応答時間・件数を設定します（「＋ 種別を追加」で種別を増やせます）。
2. 必要に応じてランチ枠を有効化し、特別枠（休憩など）を追加します。
3. 発表コマは開始時刻から順に並び、固定枠にぶつかるとその後ろに続きます。表内で発表タイトル・発表者を編集できます。
4. 行左端の ⠿ をドラッグ、または ▲▼ で発表の順序を入れ替えられます（種別をまたいだ入れ替えもできます）。
5. 「CSVエクスポート」で保存、「CSVインポート」で読み込み、「印刷 / PDF」で配布用に出力できます。
> 注意：編集内容はブラウザに保存されません。作成した表は **CSVエクスポート** で保存してください。
 
### 発表申込リスト（時刻なしCSV）から作る場合
 
1. 先に「発表種別」で、CSVに出てくる種別名・発表時間・質疑応答時間を定義しておきます（名称が一致すれば、その内訳がそのまま使われます）。
2. 「CSVインポート」で `発表種別,タイトル,発表者` のようなCSVを読み込みます。CSVの行順が発表順になります。
3. 基本設定の**開始時刻**を指定します（ランチ・特別枠も必要に応じて追加）。時刻は自動で振り直されます。
4. ⠿ のドラッグ、または ▲▼ で発表順を並び替えて完成です。
 
## CSVフォーマット
 
エクスポートは次の6列です。インポートは**見出し行の語で列を判定**するため、列の順序は自由で、不要な列は省略できます。

| 列 | 内容 |
| --- | --- |
| 開始時刻 | `HH:MM`（例：`09:00`）・**省略可** |
| 終了時刻 | `HH:MM`・**省略可** |
| 種別 | `発表` / `ランチ` / `休憩` / `特別`（省略時は発表として扱います） |
| タイトル | 発表タイトル、または枠の名称 |
| 発表者 | 発表者・所属（発表行のみ） |
| 発表種別 | 発表種別の名称（発表行のみ・省略可） |
 
インポート時は設定パネルにも反映され、CSVの行の並び順がそのまま発表順序になります。
 
- **すべての発表行に時刻がある場合**：CSVの時刻をそのまま使って表示します。
- **時刻の無い発表行がある場合**：時刻は使わず、CSVの行順のまま**基本設定の開始時刻から順に自動配置**します。
  つまり `発表種別,タイトル,発表者` だけのCSV（発表申込リストなど）をそのまま読み込めます。
  なお、時間帯が決まらないため、時刻の無いランチ・休憩・特別枠の行は配置されません（左パネルで追加してください）。
 
発表種別ごとのコマ長は次の順で決まります。
 
1. 同名の発表種別が左パネルに定義済みなら、その**発表＋質疑の内訳をそのまま使用**
2. CSVに時刻があればその長さ（内訳は同じ長さの既存種別から推定、無ければ質疑0分）
3. どちらも無ければ既存の定義から仮置き（通知に表示されます。左パネルで調整してください）
 
発表種別の列がない従来のCSVも読み込めます（その場合はコマの長さごとに種別を自動で作成）。
見出し行が無く時刻の列も無いCSVは、`発表種別,タイトル,発表者` の順とみなして読み込みます。
