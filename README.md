# Timetable Maker
 
発表会向けの **タイムテーブル作成ツール**
 
開始・終了時刻と発表時間を指定するだけで、発表コマを自動生成。
ランチや休憩・特別枠を挟んだプログラムをブラウザ上で組み立て、CSVで入出力できます。
サーバー・ビルド不要の**単一HTMLファイル**で、完全にオフラインで動作します。
 
https://shok1122.github.io/timetable-maker/

## 機能
 
- 開始時刻・終了時刻の指定
- 発表時間（分）・質疑応答時間（分）の指定（1コマ = 発表 + 質疑）
- ランチ枠の開始・終了指定
- 休憩・基調講演・ポスター・授賞式など、発表以外の**特別枠**を自由に定義
- 設定を変更すると即座に再生成される**インタラクティブ**なUI
- 発表タイトル・発表者を表内で直接編集
- **CSVのインポート／エクスポート**（UTF-8・Excel対応）
- 操作パネルを隠して出力する**印刷 / PDF**レイアウト

## 使い方
 
1. 左側の基本設定で開始・終了時刻、発表時間、質疑応答時間を入力します。
2. 必要に応じてランチ枠を有効化し、特別枠（休憩など）を追加します。
3. 固定枠の隙間に発表コマが自動で敷き詰められます。表内で発表タイトル・発表者を編集できます。
4. 「CSVエクスポート」で保存、「CSVインポート」で読み込み、「印刷 / PDF」で配布用に出力できます。
> 注意：編集内容はブラウザに保存されません。作成した表は **CSVエクスポート** で保存してください。
 
## CSVフォーマット
 
| 列 | 内容 |
| --- | --- |
| 開始時刻 | `HH:MM`（例：`09:00`） |
| 終了時刻 | `HH:MM` |
| 種別 | `発表` / `ランチ` / `休憩` / `特別` |
| タイトル | 発表タイトル、または枠の名称 |
| 発表者 | 発表者・所属（発表行のみ） |
 
インポート時は種別・時刻をもとに設定パネルにも反映されます。
